# Emotica Android beta

[Download Emotica 1.0-beta.8](https://github.com/tirupati17/emotica-site/releases/download/android-1.0-beta.8/emotica-android-1.0-beta.8.apk) — Android 8.0 or later.

Adds Settings feedback, shake-to-report with a reviewable screenshot, report status and feature voting. Fixes re-enabling encrypted backup after deletion and removes unused Health Connect permissions.

Includes 17-language onboarding and feeling labels, readable bright cards on dark themes, the fixed return-to-Mental-Sky shortcut, real round and rectangular exercise examples, and optional notifications. Other screens and catalogue titles may use English. iOS-compatible ZIP backup support remains included. Existing users can open Settings → Replay introduction.

This is a direct APK download. Android may ask you to allow installation from your browser. The beta is free; it is not yet a Google Play listing.

The installer is hosted as a GitHub release asset, keeping the 31MB APK out of Pages build artifacts.
